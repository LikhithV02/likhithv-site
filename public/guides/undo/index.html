Undo in Git:
reset vs revert

Everything from the video, plus the commands you'll actually type. Bookmark it for the next time you commit the wrong thing.

Already pushed? → git revert. It adds an undo commit, and history stays intact.

Still local? → git reset. It moves your branch back, as if the commit never happened.

Pick your situation

Undo the last commit, keep the changes staged local only

git reset --soft HEAD~1

The commit disappears. Your changes are still staged, ready to commit again.

Undo the last commit, keep the changes in your files local only

git reset HEAD~1

This is the default (--mixed). The commit disappears and your changes become unstaged edits.

Throw the last commit and its changes away local only · destructive

git reset --hard HEAD~1

The commit and its changes are gone, along with any uncommitted edits in tracked files. Check git status first.

Undo a commit that's already pushed safe on shared branches

git revert <commit-sha>
git push

This creates a new commit that does the exact opposite. Nobody's history breaks. Find the sha with git log --oneline.

Undo a pushed merge safe on shared branches

git revert -m 1 <merge-sha>

-m 1 keeps the main-line parent and undoes what the merge brought in.

Panic: I reset and lost a commit recovery

git reflog
git reset --hard <sha-from-reflog>

The reflog remembers where your branch pointed recently, so you can get lost commits back. It can't restore uncommitted edits that --hard discarded.

Just fix the last commit (message or a forgotten file) local only

git add forgotten-file
git commit --amend

This replaces the last commit with a corrected one. Don't amend a commit you've already pushed.

Undo a git add (not committed yet)

git restore --staged <file>

Unstages the file and keeps your edits.

reset vs revert at a glance

git resetgit revert
What it doesMoves the branch back to an earlier commitAdds a new commit that undoes an old one
HistoryRewritten: later commits drop off the branchKept: the mistake and the fix both stay
Your changes--soft staged · default unstaged · --hard goneYour files end up without the bad commit's changes
Use it onLocal commits you haven't pushedAnything already pushed or shared
Pushing afterNeeds a force push, which breaks teammates' historyA normal git push

In one line: reset rewinds, revert cancels.
