# Night Shift artwork

`concepts/` contains the original generated room compositions and the selected mobile crop. `operations-room-refined.jpg` is the chosen source for the optimized AVIF, WebP, and JPEG assets in `public/`.

`previews/` contains review screenshots of the homepage and featured Short card. Website text, controls, logos, and diagrams are HTML, SVG, and CSS rather than part of the generated room image.
